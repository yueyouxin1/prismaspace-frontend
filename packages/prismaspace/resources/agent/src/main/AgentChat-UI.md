## 🪄 顶级 UI 设计指导与模块拆解：Agent 对话组件 V2

### 1. 导师的整体设计思路 (Master's Design Vision)

伙计们，我们这次的核心设计哲学是**“沉浸式焦点 (Immersive Focus)”**。用户来这里不是为了欣赏花哨的按钮和分割线，他们是为了与 Agent 进行高质量的对话。因此，我们的设计任务就是**消除一切视觉噪音**，创造一个如同无边泳池般宁静、无缝的对话环境。

- **情绪板 (Mood Board)**：想象一下，我们不是在设计一个软件界面，而是在设计一个高品质的**阅读空间**。像是一间只有柔和天光的极简书房，或是 Vercel、Linear 那样，专业、冷静但又充满力量感。
- **色彩搭配 (Color Palette)**：我们将采用**中性色和单色体系**。整个界面以大面积的柔和背景色为基底，仅用不同灰度的文字和极其克制的点缀色来构建视觉层级。
  - **基底背景 (Base Background)**: `var(--ui-background)`，一个非常浅的、几乎感觉不到的灰色，比如 `#F9FAFB` 或者纯白 `#FFFFFF`，确保与头部无缝衔接。
  - **主要文本 (Primary Text)**: `var(--ui-text-primary)`，使用接近纯黑的深石板灰，如 `#111827`，保证最高的可读性。
  - **次要/辅助文本 (Secondary Text)**: `var(--ui-text-secondary)`，使用中度灰色，如 `#6B7280`，用于 Placeholder、时间戳等。
  - **边框/分隔线 (Borders/Dividers)**: `var(--ui-border)`，一个极其微妙的浅灰色 `#F3F4F6`，而且我们要**极度吝啬地使用它**。头部和对话区的分割线，必须拿掉！
- **排版性格 (Typography)**：现代、清晰、无需衬线。推荐使用系统默认 UI 字体或 `Inter` 字体族。字重对比是我们的核心武器。**主标题用 `font-weight: 600` (Semibold) 或 `700` (Bold) 来定调，正文用 `400` (Regular) 来叙事**。行高 `line-height` 控制在 `1.6` 左右，让长文本阅读呼吸顺畅。

### 2. 全局布局与代码架构 (Global Layout & Architecture)

在动手之前，先想好骨架。我很高兴看到你们提到了组件化拆分，这是专业团队的正确做法。

- **宏观布局**：这是一个经典的 `Flexbox` 布局。
  - **桌面端**：`display: flex`。左侧是 `<SessionList />` (会话列表)，宽度固定（比如 `260px`）。右侧是 `<ChatView />` (对话视图)，占据剩余所有空间 (`flex: 1`)。
  - **移动端**：`<SessionList />` 默认隐藏或以抽屉形式存在，通过一个 `IconButton` 触发。`<ChatView />` 占据整个屏幕。
- **组件化拆分策略 (Code Structure)**：
  - `AgentShell.vue`: 根组件，负责整体布局和状态管理。
  - `components/AgentHeader.vue`: 顶部栏。
  - `components/SessionList.vue`: 左侧会话历史。
  - `components/ConversationView.vue`: 右侧核心对话区域。
  - `components/Composer.vue`: 位于底部的输入框区域。
  - `components/EmptyState.vue`: 对话区无消息时的初始欢迎状态。
- **目标落地位置**：`prismaspace-frontend/packages/prismaspace/resources/agent/src/main`
- **核心参考实现**：`reference_example/ai-elements-vue-main/packages/examples/src/chatbot.vue` (我们将基于它的逻辑，注入我们全新的“皮肤和骨架”)

### 3. 【核心】模块拆解与极详元素清单

现在，让我们戴上显微镜，一个像素一个像素地来雕琢每个模块。

#### A. 头部 (`AgentHeader.vue`)

**大局观**：这不再是一个“区域”，它只是对话画布顶部的**一层薄雾**，提供最核心的导航。**绝对不要有下边框！** 它和下面的对话区是**一整块无缝的玻璃**。

- **布局思路**：一个高度约为 `60px` 的 `Flex` 容器，`align-items: center`，`justify-content: space-between`，左右内边距 `padding` 设定为 `24px`。
- **详尽元素清单 (桌面端)**：
  - **左侧区域 (`flex items-center gap-4`)**
    - **Agent 名称 (Agent Name)**：
      - **视觉指导**：这是品牌的展示，必须清晰有力。使用 `font-weight: 500` (Medium)，字号 `16px`，颜色用我们的主文本色 `#111827`。
  - **右侧区域**
    - （可选）**更多操作按钮 (More Actions)**：一个极简的 "..." (三个点) `IconButton`。悬停时才显示一个柔和的背景，点击后弹出菜单（如：分享、设置等）。暂时可以先不加，保持极致干净。
- **详尽元素清单 (移动端)**：
  - **左侧区域 (`flex items-center gap-2`)**
    - **展开/收起菜单按钮 (Menu Toggle)**：一个标准的 `Hamburger Icon`，用于打开 `<SessionList />` 抽屉。必须是一个 `40px * 40px` 的热区，图标本身 `20px`。
    - **新建对话按钮 (New Chat)**：一个 `Plus` 或者“对话气泡+”的图标按钮。
    - **Agent 名称 (Agent Name)**：同桌面端。

#### B. 对话区 (`ConversationView.vue`)

**大局观**：这里是舞台的中央。当没有对话时，它应该优雅地引导用户开始；当有对话时，它要让信息流清晰、舒适。

- **1. 初始空状态 (`EmptyState.vue`)**
  - **布局思路**：`Flex-col` 垂直居中布局，`justify-content: center`，`align-items: center`。
  - **详尽元素清单**：
    - **欢迎语 (Welcome Text)**
      - **视觉指导**：一个巨大的、充满呼吸感的标题。参考图里的 “Hi, 昌松”。
      - **样式范式**：`font-size: 36px`，`font-weight: 700` (Bold)，颜色用主文本色 `#111827`。距离下方的卡片组要有足够的留白，大概 `48px`。
    - **预设问题卡片组 (Preset Prompt Cards)**
      - **布局思路**：一个 `Grid` 布局，`grid-template-columns: repeat(auto-fit, minmax(200px, 1fr))`，让它在不同宽度下能自动换行。`gap` 设置为 `16px`。
      - **单个卡片 (`PromptCard.vue`)**
        - **容器**：一个带有 `border-radius: 12px` 的容器，`padding: 16px`。背景色用我们定义的二级背景 `#F3F4F6`。**不要边框！** 靠背景色区分。
        - **内部元素**：
          - **主标题 (e.g., "元气指南")**: `font-weight: 500` (Medium)，`font-size: 14px`，主文本色。
          - **副标题 (e.g., "15分钟高效家庭训练")**: `font-size: 12px`，次要文本色 `#6B7280`。上下标题间距 `4px`。

- **2. 对话消息流 (Message Bubbles)**
  - **布局思路**：使用 `ai-elements/Conversation` 组件，它已经处理好了消息列表的渲染。我们要做的，是为它提供定制化的“皮肤”。
  - **AI 消息体 (AI Message)**
    - **外容器**：`max-width` 限制在 `85%` 左右，避免过长。`align-self: flex-start`。
    - **"深度思考"提示 (Thinking Indicator)**
      - **视觉指导**：这是个很好的细节。它应该轻巧、不打扰。
      - **样式范式**：`font-size: 12px`，次要文本色，前面可以加个小小的 `Sparkle` 或 `Brain` 图标。点击可展开/收起思考过程。
    - **消息内容 (Content)**：标准排版，`line-height: 1.6`。
    - **操作栏 (Action Toolbar)**
      - **布局思路**：`Flex` 布局，`gap: 8px`，放在消息内容下方，与内容有 `12px` 的间距。
      - **元素清单**：`Copy`, `Regenerate`, `Like`, `Dislike` 等图标按钮。
      - **视觉指导**：图标尺寸 `16px`，颜色为次要文本色。悬停时图标颜色加深，并出现一个 `24px * 24px` 的圆形、极淡的灰色背景 `rgba(0,0,0,0.05)`，给用户一个清晰的点击反馈。
  - **用户消息体 (User Message)**
    - **外容器**：`align-self: flex-end`，可以给一个极其微妙的背景色，比如非常淡的蓝色调 `#EFF6FF`，或者就是和 AI 消息一样的白色/浅灰色，仅靠左右对齐来区分。保持极简。

#### C. 输入框 (`Composer.vue`)

**大局观**：这是用户将想法转化为行动的地方。它必须感觉**轻盈、响应迅速且功能强大**。告别傻大黑粗，我们要的是一个精致的工具条。

- **布局思路**：一个 `Flex` 容器，`align-items: flex-end` (让发送按钮和输入框底边对齐)。整个容器有一个明显的 `border-radius: 999px` (胶囊形状) 或 `24px` (圆角矩形)，并带有柔和的 `box-shadow` 让它从背景中“浮”起来。背景色为纯白 `#FFFFFF`。
- **详尽元素清单 (从左到右)**：
  - **左侧工具栏 (Toolbar)**
    - **布局**：`Flex` 布局，`gap: 4px`，放在输入框左侧。
    - **元素清单**：参考图里的 `附件 (Upload)`、`插件/工具 (Tools)` 等图标按钮。
    - **视觉指导**：同样是 `IconButton` 样式，悬停有柔和背景反馈。
  - **文本输入区 (`Textarea`)**
    - **视觉指导**：这是核心！`height` 应该能自动增长，`min-height` 设为 `24px` 左右 (单行文本的高度)，`max-height` 限制在 `200px` 左右。**关键：`background: transparent`，`border: none`，`resize: none`**。这样它看起来就像直接在那个白色容器里写字。
    - **Placeholder 文本**：“你有什么想知道的，快来问问我”，颜色为次要文本色 `#6B7280`。
  - **右侧操作区 (Actions)**
    - **添加文件按钮 (Attach file)**：一个 `+` 图标按钮。
    - **发送按钮 (Send Button)**
      - **容器**：一个圆形按钮，尺寸 `32px * 32px`。
      - **状态**：
        - **禁用时 (输入框为空)**：背景色为浅灰色 `#F3F4F6`，内部的发送 `Paper Plane` 图标颜色为更浅的灰色。
        - **激活时 (输入框有内容)**：背景色变为品牌主色或一个醒目的颜色（比如深灰色 `#111827`），图标变为白色。这个状态转变要干脆利落。

### 4. 丝滑微交互与动效剧本 (Micro-interactions)

- **滚动物理 (Scrolling Physics)**：
  - **新消息出现**：当新消息（自己发的或 AI 回复的）出现时，滚动条必须用 `behavior: 'smooth'` 平滑滚动到底部。
  - **流式生成**：`ai-elements` 已经处理得很好。我们要确保缓动曲线是 `ease-out`，感觉像是一个物体自然减速停止，而不是生硬地瞬移。
  - **用户接管**：**这是一个铁律**。一旦用户在 AI 流式输出时手动滚动了滚动条，程序必须**立即停止**任何自动滚动行为。用户的意图永远是第一位的。
- **悬停反馈 (Hover Feedback)**：
  - **所有可点击元素**（按钮、卡片、链接），鼠标悬停时都要有反馈。
  - **推荐动效**：一个 `150ms` 的 `ease-out` 过渡。比如图标按钮背景色渐显，或者预设问题卡片轻微上浮 `transform: translateY(-2px)` 并伴随一个更深的弥散阴影 `box-shadow`。
- **点击反馈 (Active State)**：
  - 所有按钮在被点击时（`:active` 状态），都应该有一个轻微的 `transform: scale(0.95)` 效果，模拟被按下去的物理感觉。

### 5. 大师级还原度 CheckList (QA Checklist)

交给你们的开发和测试同学，对着这个清单逐项检查，确保我们的作品达到了像素级的完美。

- `[ ]` **视觉统一性**：整个组件的背景色是否完全统一，头部与对话区之间是否存在任何 1px 的边框线？
- `[ ]` **头部布局**：在桌面端和移动端，头部的元素是否按照设计文档精确布局，多余的元素是否已彻底移除？
- `[ ]-` **空状态呈现**：初次进入对话时，是否展示了居中的欢迎语和优雅的预设问题卡片网格？卡片的圆角、间距、内边距是否正确？
- `[ ]` **输入框形态**：输入框是否是圆角/胶囊形态？高度是否能随内容自动撑开？Placeholder 文本是否正确？
- `[ ]` **发送按钮状态**：输入框为空时，发送按钮是否处于明确的禁用状态？输入内容后，它是否立刻转变为醒目的激活状态？
- `[ ]` **消息流对齐**：用户消息是否靠右，AI 消息是否靠左？
- `[ ]` **图标交互**：AI 消息下方的操作图标，以及输入框旁边的工具图标，在鼠标悬停时是否有柔和的背景反馈？点击时是否有“按下”的动效？
- `[ ]` **滚动行为**：AI 流式输出时，页面是否平滑滚动？当我手动滚动时，自动滚动是否立即停止？
- `[ ]` **字体层级**：Agent 名称、欢迎语、卡片标题、卡片副标题、消息正文的字重和字号对比是否清晰，符合设计规范？
